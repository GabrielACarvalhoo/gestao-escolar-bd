# Sistema de Gestão Escolar — Banco de Dados

Trabalho da disciplina **Laboratório de Banco de Dados** — proposta de sistema de banco de dados com modelagem conceitual, lógica, física e implementação em MySQL.

## 📋 Sobre o projeto

Sistema de matrícula e gestão escolar: alunos, turmas organizadas por série, disciplinas, professores (incluindo professor regente), avaliações (notas) e responsáveis pelos alunos.

## 🎯 Objetivo do trabalho

Desenvolver uma proposta de sistema de banco de dados, com modelagem (conceitual, lógica e física) e implementação.

## 📅 Entrega

**Prazo:** 20 de setembro de 2026, 23:59
**Formato:** documento PDF + link deste repositório

## 📦 O que precisa estar no PDF final

- [ ] Tema escolhido e descrição (contexto, justificativa, escopo)
- [ ] DER Conceitual completo (entidades fortes/fracas/associativas/especializadas; relacionamentos 1:1/1:N/M:N/binário/ternário/com atributo; atributos simples/compostos/multivalorados)
- [ ] Modelagem Lógica (tabelas, tipos, PKs, FKs)
- [ ] Modelagem Física (MySQL, constraints, normalização)
- [ ] Link deste repositório

## 💻 O que precisa estar no repositório

- [ ] Script `.sql` de criação das tabelas (DDL)
- [ ] Script `.sql` de população do banco (DML — inserts)
- [ ] Script `.sql` com SELECTs e UPDATEs de exemplo

## ✅ Critérios de avaliação

- Clareza e coerência na descrição do tema
- Complexidade e diversidade na modelagem
- Correção técnica do DER
- Coerência entre os modelos conceitual, lógico e físico
- Apresentação visual e organização do documento
- Participação dos membros do grupo
- Qualidade técnica e organização do código
- Correção e funcionalidade dos scripts
- Clareza na documentação

## 🗂️ Como estamos organizando o trabalho

Usamos o [Project board](https://github.com/users/GabrielACarvalho/projects/5) deste repositório pra dividir e acompanhar as tarefas. Fluxo das colunas:

| Coluna | O que significa |
|---|---|
| **Criação de Tarefas** | Backlog — tarefas propostas, ainda não iniciadas |
| **Tarefas em Tiragem** | Disponíveis pra alguém pegar |
| **Em andamento** | Alguém já está trabalhando nisso |
| **Em análise** | Feito, passando por revisão antes de considerar pronto |
| **Concluídas** | Validado e já incorporado ao trabalho |

Cada tarefa é uma **Issue**. O resultado de cada uma fica documentado como **comentário** na própria issue (ex: a decisão do tema está comentada na issue #1).
